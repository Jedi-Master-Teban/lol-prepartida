## Qué construyes
Funciones puras (sin leer archivos, sin red, sin base de datos) que resumen un equipo de campeones y comparan dos equipos. El resultado alimenta las reglas del briefing (D04a).

## Entrada: las fichas
`fichas` es un diccionario `{nombre_de_campeón: ficha}` (lo que devuelve `conocimiento.leer_fichas`). Una ficha tiene: `dano` ("fisico", "magico" o "mixto"), `alcance` ("cuerpo" o "distancia"), `etiquetas_riot`, `enganche` (0 a 3, o `""` si falta), `control` (0 a 3, o `""`), `escala` ("temprano", "medio", "tardio" o `""`), `arquetipo` (texto o `""`), `verificado` (booleano).

**Un campeón es "conocido" solo si tiene ficha y `ficha["verificado"] is True`.** Los demás (sin ficha o sin verificar) son "desconocidos": no cuentan para nada, solo se listan.

## Funciones (nombres y firmas exactas)
```python
def perfil_equipo(campeones: list[str], fichas: dict[str, dict]) -> dict
def contraste(aliado: dict, enemigo: dict) -> dict
def construir_contexto(aliados: list[str], enemigos: list[str], fichas: dict[str, dict]) -> dict
```

### `perfil_equipo`
Devuelve un diccionario con **exactamente** estas claves:
| Clave | Valor |
|---|---|
| `prop_fisico` | float. Por cada conocido: "fisico" suma 1 al daño físico, "mixto" suma 0.5 al físico y 0.5 al mágico. `prop_fisico = suma_fisico / n_conocidos`. Redondea a 6 decimales con `round(x, 6)`. Si no hay conocidos: `0.0` |
| `prop_magico` | float. Igual, con "magico" y la otra mitad del "mixto". Si no hay conocidos: `0.0` |
| `enganche_total` | int. Suma de `enganche` de los conocidos; un `""` vale 0 |
| `control_total` | int. Igual con `control` |
| `escala_dominante` | `"temprano"`, `"medio"`, `"tardio"` o `""`. La que más se repite entre los conocidos (ignora los `""`). **Empate:** gana la que va primero en el orden `temprano`, `medio`, `tardio`. Sin datos: `""` |
| `arquetipos` | lista de textos **sin repetir, sin vacíos y ordenada alfabéticamente** |
| `n_cuerpo` | int. Cuántos conocidos tienen `alcance == "cuerpo"` |
| `n_conocidos` | int |
| `desconocidos` | lista de nombres, **en el orden en que llegaron** en `campeones` |

### `contraste(aliado, enemigo)`
`aliado` y `enemigo` son los diccionarios que devuelve `perfil_equipo`. Devuelve **exactamente** estas claves:
| Clave | Valor |
|---|---|
| `dif_enganche` | `aliado["enganche_total"] - enemigo["enganche_total"]` |
| `dif_control` | igual con `control_total` |
| `mas_enganche` | `"aliado"` si el total aliado es mayor, `"enemigo"` si el del enemigo es mayor, `"igual"` si empatan |
| `mas_control` | igual con `control_total` |
| `mejor_escala` | compara `escala_dominante` con el orden `temprano < medio < tardio`: `"aliado"` si la del aliado es más tardía, `"enemigo"` si la del enemigo lo es, `"igual"` si son iguales **o si falta alguna de las dos (`""`)** |
| `enemigo_casi_todo_fisico` | `enemigo["prop_fisico"] >= 0.7` |
| `enemigo_casi_todo_magico` | `enemigo["prop_magico"] >= 0.7` |
| `enemigo_un_tipo_dano` | `True` si cualquiera de los dos anteriores es `True` |

### `construir_contexto(aliados, enemigos, fichas)`
Devuelve `{"aliado": perfil_equipo(aliados, fichas), "enemigo": perfil_equipo(enemigos, fichas), "contraste": contraste(aliado, enemigo)}`.

## Reglas generales
- No modifiques las listas ni los diccionarios que recibes.
- Un valor de `enganche`/`control` que no sea número (por ejemplo `""`) vale 0. Cuidado: `True`/`False` no cuentan como número aquí.
- No leas `conocimiento/campeones.toml`: las pruebas usan fichas inventadas.
- Docstring de una línea en cada función pública y `from __future__ import annotations` al inicio.
